Connector Webhooks - Glue Outbound

Outbound webhook integration for connector backends.

Overview

Connector Webhooks - Glue Outbound provides an opt-in mixin (bwt.connector.webhook.outbound.mixin) that connector backends inherit to gain fully automated outbound webhook provisioning and delivery. Endpoints are templated, provisioned, and linked automatically; deliveries are built and queued via queue_job.

Key Features

  • Adds connector_backend_ref on outbound endpoints and a computed outbound_endpoint_id on the backend
  • Outbound dispatch hook (_handle_outbound_webhook_delivery(delivery, request)) routed via the framework's _invoke_handler
  • Outbound response hook (_handle_outbound_webhook_response(delivery, response, state, outcome, *, binding, operation)) with the binding and operation pre-resolved by the overlay
  • Per-backend hooks _get_outbound_api_base_url(delivery) and _get_outbound_extra_headers(delivery) consumed by the framework when rendering the URL and merging request headers
  • Delivery factory (queue_outbound_delivery) and get_outbound_endpoint resolver
  • Form/list action to navigate to the linked outbound endpoint(s)

Dependencies

  • bwt_connector_webhooks_core
  • bwt_webhooks_outbound
