Rollout

Rollout Path

A typical rollout keeps outbound ownership on the backend while the framework manages delivery and recovery around it.

Rollout Steps

  1. Prepare the backend so it can own outbound delivery.
  2. Seed or install the outbound endpoints that belong to that backend.
  3. Let business flows resolve the right endpoint and queue delivery work.
  4. Let the framework manage dispatch and response handling around the connector.
  5. Use delivery states to retry, review, or close work cleanly.
